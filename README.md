⚽ Football Analyzer

A Python-based football data analysis tool that fetches real match data from online CSV sources and performs advanced analytics such as:

- 📊 Goals analysis (home & away)
- 🏆 Best teams by win rate
- 🎯 Shot rate efficiency
- 🛡️ Defensive performance
- 👑 League champion prediction

---

🚀 Features

- 🔍 Analyze football data from multiple leagues (E0, E1, E2, etc.)
- 📈 Visualize team performance using graphs
- 🧠 Calculate win rates and shot efficiency
- 🛡️ Identify best defensive teams
- 👑 Predict league champions using points system
- 🎨 Rich CLI interface with tables, colors, and emojis

⚙️ Installation

1. Clone the repository:

git clone https://github.com/your-username/football-analyzer.git
cd football-analyzer

2. Install dependencies:

pip install -r requirements.txt

---

▶️ Usage

Run the program:

python main.py

Then:

1. Select season (e.g. 1718)
2. Select league (E0, E1, etc.)
3. Choose analysis option from menu

---

📊 Example Features

🏆 Champion Calculation

Uses standard football scoring:

- Win → 3 points
- Draw → 1 point
- Loss → 0 points

🎯 Shot Rate

Shot Rate = Goals / Total Shots

🛡️ Defense Strength

Defense = Goals Conceded (lower is better)
